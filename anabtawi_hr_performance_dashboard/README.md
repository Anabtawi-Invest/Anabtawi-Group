# Anabtawi HR Performance Dashboard

Odoo 19 module for HR performance dashboards based on ISO 30414 reporting areas.

Install:
1. Copy `anabtawi_hr_performance_dashboard` to your Odoo custom addons path.
2. Update Apps List.
3. Install "Anabtawi HR Performance Dashboard".
4. Go to Employees > HR Performance > Reporting Periods, create a period, and click Compute KPIs.

The module computes available KPIs from standard Odoo HR/Accounting data and leaves specialized KPIs as editable manual values until matching Anabtawi operational modules are added.
