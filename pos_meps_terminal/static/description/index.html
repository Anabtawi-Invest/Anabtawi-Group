MEPS / ApexECR Payment Terminal for Point of Sale

Real card payments from Odoo POS - no manual entry, no re-keying amounts.

Automatic Sale

Selecting a MEPS payment method in POS sends the amount straight to the physical EFTPOS terminal over the official SOAP web service and waits for the customer to tap/insert/swipe. No typing amounts twice.

Void & Settlement

Void a completed sale and run end-of-day terminal settlement directly from the Payment Method form in the backend.

Multi-branch, Multi-terminal

Every branch/terminal has its own Terminal ID, Merchant ID and Secure Key, configured per Payment Method - one company, any number of terminals.

Set up in minutes

  1. Install the module.
  2. Settings > Point of Sale > MEPS Connection - confirm the gateway URL and timeout (production values pre-filled).
  3. Point of Sale > Configuration > Import MEPS Terminals - upload the Tid/Mid/SecureKey Excel sheet your acquirer gave you, or fill one Payment Method by hand.
  4. Assign the resulting "MEPS - ..." payment method(s) to your POS config(s).
  5. Open a POS session and take a card payment.

Nothing hardcoded

This module ships with zero customer-specific data. Every terminal, key and endpoint is configured after install through the UI or a one-click Excel import, so the same module works for any MEPS merchant.

Requires a MEPS/ApexECR merchant account and Terminal IDs activated for WEB-ECR by your acquirer.
